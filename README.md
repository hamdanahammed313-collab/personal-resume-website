# Hamdan Ahammed — Personal Resume Website

A responsive personal portfolio built with semantic HTML and plain CSS.

## Files
- `index.html` — page structure and content
- `style.css` — theme, layout, typography, responsive rules and hover states
- `images/profile.jpg` — add your own portrait here

## Run locally
Open `index.html` in a browser. For a local development server, open the folder in VS Code and use Live Server.

## Personalise before publishing
1. Your supplied portrait is included as `images/profile.jpg`.
2. The contact email is set to `hamdan.am26@iimb.ac.in`.
3. Replace the LinkedIn and GitHub links with your actual profile URLs.
4. Fill in your school names, stream and years in the Education section.
5. Add links to project demos/repositories if you want to make them public.
6. Check every project and experience description for accuracy before submitting.

## Publish using GitHub Pages
1. Create or open your existing GitHub repository.
2. Upload `index.html`, `style.css`, and the `images` folder to the repository root (keep this structure).
3. Commit and push the changes.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the deployment and open the published URL shown in the Pages settings.

## CSS concepts demonstrated
Element, class and ID selectors; CSS custom properties; Flexbox; CSS Grid; sticky positioning; hover states; transitions; media queries; responsive image sizing; pseudo-elements; and reduced-motion accessibility.
